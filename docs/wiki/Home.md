# Ghost Chat — Fork Wiki

Welcome to the **superchilpil/ghost-chat** fork of Ghost Chat.

This fork is based on the original Ghost Chat project created by **Enubia**. The original project remains credited in the repository's [Credits and attribution](../../README.md#credits-and-attribution) section.

## What this fork adds

- Automatic live detection for Twitch, YouTube, and Kick
- Automatic chat connection when configured streams go live
- Per-platform Auto Connect
- Background monitoring while Ghost Chat is hidden
- Configurable live detection intervals
- Automatic bring-to-front and vanish/click-through behavior
- Windows system-tray integration
- Persistent configuration and window state
- YouTube low-latency StreamList chat transport with fallback
- Connection diagnostics
- Windows portable and NSIS installer releases
- Automatic update handling for installed Windows builds
