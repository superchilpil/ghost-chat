# Bug Reports

## Where to report problems

Bug reports should be filed against this fork:

https://github.com/superchilpil/ghost-chat/issues

Do not send fork-specific bug reports to the original Enubia repository.

## What to include

Please include:

- Ghost Chat version
- Windows or macOS
- Installed or portable build
- Platform affected (Twitch, YouTube, Kick)
- Steps to reproduce the problem
- What you expected to happen
- What actually happened
- Any error message or diagnostic information
- Relevant screenshots when useful

## For live detection problems

Also include:

- Which platform was being monitored
- Whether Auto Connect was enabled
- The configured poll interval
- Whether Ghost Chat was visible or in the tray
- Whether manual connection worked

## For YouTube problems

Include any connection diagnostic information showing the active transport.
