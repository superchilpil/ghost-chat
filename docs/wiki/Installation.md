# Installation

## Windows

For normal users, download the latest release from:

https://github.com/superchilpil/ghost-chat/releases/latest

### Installer

1. Download **ghost-chat-Setup-X.Y.Z.exe**.
2. Run the installer.
3. Launch Ghost Chat.
4. Configure your Twitch, YouTube, and/or Kick channel.
5. Enable **Auto Connect** for any platform you want monitored automatically.

The installer does not require Git, Go, Node.js, pnpm, Wails, or a development environment.

### Portable version

Download **ghost-chat.exe** from the latest release and run it directly.

The portable build does not install Ghost Chat into Windows and does not use the automatic installer update path.

## Updating

Installed Windows builds can use the built-in update notification to download and launch the latest NSIS installer.

Portable builds continue to direct users to the fork's GitHub releases instead of silently installing an update.

## macOS

macOS builds are published through GitHub Actions. The maintainer does not currently have access to a Mac for personal testing, so macOS users should report platform-specific problems through this fork's support channels.
